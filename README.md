# TRADEBOT — панель

Страница мини-приложения Telegram для бота TRADEBOT.

- Здесь только оформление и показ: ни ключей, ни данных клиентов в репозитории нет.
- Цифры клиента бот передаёт при открытии панели в ссылке после `#d=` — эта часть адреса не отправляется на сервер страницы.
- Кнопки панели ничего не делают сами: они открывают чат с ботом командой `/start p_…`, и действие выполняет бот (бюджет копилки — после подтверждения в чате).

Адрес страницы вписывается боту в `.env`: `PANEL_URL=https://kaweuka1-glitch.github.io/tradebot-panel/`.
